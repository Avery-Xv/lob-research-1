# NP05 深圳撤单价格语义审计

结论：`FAIL`。现有 R018/NP05 结果不得解释。

深圳 V4 的 `CANCEL` 行在抽查样本中买卖方向和对应订单 ID 正常，但 `source_price` 为 0。当前 F013 引擎直接以该价格判断撤单是否位于盘口附近，于是买撤单永远不能通过买侧条件，而卖撤单几乎机械地通过卖侧条件。全市场产物因此出现深圳 `near_cancel_buy` 全为 0、signed imbalance 与 absolute imbalance 完全相等的退化。

修复不能把 0 价直接替换成买一或卖一。应按 `(date, side, order_id)` 从此前的同侧报单状态恢复委托原价，并覆盖 09:30 前集合竞价产生、10:29 仍可撤销的订单。修复后必须重新跑 Q005/Q008、受影响的 F013 撤单字段、F014 候选和 R018；R014–R017 不读取这两个撤单字段，不受本缺陷影响。
