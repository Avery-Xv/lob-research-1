# 近端大单遮挡与深档撤单响应因子设计文档

## 1. 文档定位

本文档定义“近端大单遮挡—深档撤单响应”因子，并给出从逐笔事件构造事件级指标、日内状态变量和日频因子的完整方案。

该因子研究的核心问题是：

> 当某一侧近端盘口出现异常大的被动挂单后，同侧更差价格上的既有订单是否因为预期成交概率下降而更倾向于撤单？

例如，买一或买二出现大额买单后，更深位置的既有买单需要等待该大单及其他更优价订单被消耗后才可能成交。若其成交等待时间和机会成本上升，深档买单可能更快撤销；卖侧逻辑对称。

本研究首先验证订单行为机制，其次才研究未来收益。即使深档撤单反应稳定存在，也不能直接推出固定的收益预测方向。建议将指标拆为：

1. 无方向的遮挡响应强度；
2. 买卖侧不对称的方向信号；
3. 结合近端大单持续性的可信度信号；
4. 近端大单消失后的流动性脆弱性信号。

证据等级暂定为 **C**：逻辑可检验，但因子定义、作用方向和样本外稳定性均需实证确认。

## 2. 经济逻辑

### 2.1 价格优先产生的遮挡效应

设方向 $s\in\{B,A\}$ 分别表示买侧和卖侧。订单 $o$ 位于同侧较深价格 $p_o$，其成交前通常需要：

1. 所有更优价格上的订单被主动成交消耗或自行撤销；
2. 市场价格移动到订单所在价位；
3. 同价位排在其前方的队列被消耗。

若时点 $t_e$ 在更优价格 $p_e$ 新增大额被动订单 $q_e$，且 $p_e$ 严格优于 $p_o$，则订单 $o$ 前方需要消耗的总流动性增加。对固定预测窗口 $h$，有：

\[
P(\text{fill}_o\le t_e+h\mid q_e\text{出现})
<
P(\text{fill}_o\le t_e+h\mid q_e\text{未出现})
\]

成交机会下降会增加等待成本、库存机会成本和重新定价需求，因此可能提高撤单风险。

### 2.2 为什么只研究“同侧、更差价格、事件前已有订单”

- **同侧**：近端大买单首先遮挡更深买单，近端大卖单首先遮挡更深卖单。
- **更差价格**：新增订单必须严格位于目标订单之前，才存在价格优先意义上的遮挡。
- **事件前已有订单**：只有这些订单的后续行为可以解释为对大单到达的响应。大单出现后新挂又撤的订单不属于同一机制。
- **不纳入同价位既有订单**：价格—时间优先下，后来新增的大单通常排在同价位既有订单之后，不会降低这些既有订单的队列优先级。

### 2.3 可能的信号含义

深档撤单响应不只描述流动性减少，也可能反映市场对近端大单的判断：

- 大单持续存在，深档快速撤单：其他订单可能认为遮挡真实且会持续；
- 大单很快消失，深档几乎不响应：市场可能将其视为短暂噪声；
- 深档先撤，大单随后也撤：原有同侧流动性已退出，近端支撑或压制突然消失，盘口可能形成流动性空洞；
- 两侧同时出现强遮挡响应：更可能代表总体订单更新加速和流动性不稳定，而非明确方向。

## 3. 研究假说

### 3.1 机制假说

- **H1 遮挡反应**：近端大单出现后，同侧、更差价格上的既有订单撤单率上升。
- **H2 剂量效应**：近端新增量相对于正常盘口越大，深档异常撤单反应越强。
- **H3 距离衰减**：反应优先出现在大单后方最近的若干价格层，并随价格距离扩大而减弱。
- **H4 持续性效应**：持续时间更长、剩余量衰减更慢的大单，引发的深档撤单反应更强。
- **H5 成交机会渠道**：在匹配的盘口状态下，近端大单出现后，深档既有订单的触价率或成交风险下降，撤单风险上升。

### 3.2 因子假说

- **H6 可信大单方向**：持续性高且引发强深档反应的大买单偏多，持续性高且引发强深档反应的大卖单偏空。
- **H7 流动性空洞**：深档已明显撤销而近端大单随后快速消失时，价格向该侧不利方向跳变的风险上升。
- **H8 无方向风险**：双侧遮挡响应强度都高，可能预测更高的短期波动率、价差和流动性恢复成本。

H6—H8 仅是待检验方向，不应在回测前写死为收益结论。

## 4. 数据要求

### 4.1 严格订单级版本

推荐使用统一排序的逐笔委托、撤单、成交数据，并能够重建每张订单的剩余数量和价格优先级。至少需要：

| 类别 | 必要字段 |
|---|---|
| 事件标识 | `symbol`、`trade_date`、`event_time`、`event_seq` 或 `row_id` |
| 新增订单 | `order_id`、`side`、`order_price`、`order_qty`、`order_type` |
| 撤单 | `order_id`、`cancel_qty`、`cancel_time`、`cancel_seq` |
| 成交 | `trade_id`、`trade_price`、`trade_qty`、`buy_order_id`、`sell_order_id` |
| 盘口 | 事件前或可由上一事件恢复的各档价格、数量、订单数 |

若当前数据每行保存事件后的完整盘口，则事件 $i$ 的事件前盘口来自同股票、同交易日排序后的第 $i-1$ 行。

### 4.2 快照近似版本

只有固定频率 Level-2 快照时，可以计算近似版本，但存在三类限制：

1. 无法准确识别深档减少来自撤单还是成交；
2. 价格档位移出可见深度时，不能将其误判为撤单；
3. 同一快照间隔内的大单新增、成交和撤销可能相互抵消。

因此，快照版本只适合初筛。若缺少逐笔撤单或订单 ID，应将指标命名为“深档净流失响应”，不能直接称为既有订单撤单率。

### 4.3 样本过滤

第一版建议：

- 仅使用连续竞价；
- 排除开盘和收盘集合竞价；
- 排除停牌、长期封板和盘口数据明显不完整的股票日；
- 对午间休市前后分别处理，不把休市时长计入反应窗口；
- 排除事件乱序、订单连接率过低、撤单量超过订单剩余量等异常股票日；
- 对涨跌停附近样本单独分组，不与普通盘口直接混合。

## 5. 事件前订单状态

按股票、交易日维护订单状态表：

```text
order_state[order_key] = {
    side,
    price,
    entry_time,
    entry_seq,
    initial_qty,
    remaining_qty,
    cumulative_trade_qty,
    cumulative_cancel_qty,
    queue_ahead_qty,
    active_flag
}
```

推荐订单键：

```text
(trade_date, side, order_id, optional_recid)
```

处理原则：

- 新增订单写入状态表；
- 部分成交减少 `remaining_qty`；
- 部分撤单减少 `remaining_qty` 并累计撤单量；
- 完全成交或完全撤销后关闭订单；
- 改价若失去原优先级，应按“撤旧挂新”处理；
- 所有因子判断使用事件发生前状态，事件后状态只用于更新。

## 6. 近端大单触发事件

### 6.1 触发订单范围

主版本只使用新增后仍停留在订单簿中的被动限价单。立即成交的主动订单不属于本因子的“近端遮挡大单”。

近端区域建议定义为同侧前 $K=2$ 个价格层。稳健性测试使用 $K\in\{1,2,3\}$。

为提高识别清晰度，将触发事件拆为：

| 类型 | 定义 | 建议用途 |
|---|---|---|
| A：原价扩量 | 在事件前已有近端价格层新增挂单 | 主样本 |
| B：价差内改善 | 新订单进入买一卖一之间并形成新最优价 | 单独报告 |
| C：被动换档 | 其他订单消失导致某档变成近端，未发生真实新增 | 不作为触发 |

A 类不会改变最优报价，最适合识别“数量遮挡”。B 类同时改变价格距离和盘口中心，应作为扩展样本，不能与 A 类无条件合并。

### 6.2 大单规模

设事件 $e$ 新增数量为 $q_e$，所在方向和档位的历史正常深度为 $D^{hist}_{i,s,k,b}$，其中 $b$ 是日内时段桶。定义标准化冲击：

\[
Z_e^{size}
=
\frac{q_e}
{D^{hist}_{i,s,k,b}+\varepsilon}
\]

也可以对单笔被动委托量做历史分位标准化：

\[
U_e^{size}
=
F^{hist}_{i,s,k,b}(q_e)
\]

历史基准只能使用 $d-1$ 及更早数据。推荐第一版大单条件：

```text
U_size >= 95%
and
Z_size >= 1
```

即单笔委托位于股票自身历史同类订单前 5%，且其数量不低于该位置的典型总深度。敏感性测试使用 90%、97.5%、99% 分位，以及 `Z_size` 的 0.5、1、2 倍阈值。

### 6.3 聚集事件合并

若短时间内同侧近端连续出现多笔大单，多个反应窗口会重叠，导致同一次深档撤单被重复归因。主版本应将相邻触发合并为“大单片段”：

1. 第一笔满足阈值的订单开启片段；
2. 在冷却时间 $g$ 内同侧近端新增大单并入该片段；
3. 片段规模为新增量之和；
4. 最后一笔大单后超过 $g$ 未再触发，片段结束。

建议 $g=500$ 毫秒，并测试 100 毫秒、1 秒和固定事件数窗口。合并后，深档撤单只能归属于一个片段。

## 7. 深档既有订单集合

对触发事件 $e$，令方向为 $s_e$，触发价格为 $p_e$，事件前一刻仍在簿中的订单全集为 $\mathcal O(t_e^-)$。目标订单集合定义为：

\[
\mathcal O_e^{deep}
=
\left\{
o\in\mathcal O(t_e^-):
s_o=s_e,\ p_o\text{ 严格劣于 }p_e,
1\le d(p_o,p_e)\le J
\right\}
\]

其中，买侧的更差价格是 $p_o<p_e$，卖侧的更差价格是 $p_o>p_e$，$d(\cdot)$ 是 tick 距离。

主版本建议 $J=5$ ticks；若股票价格档位不连续，可以改用事件前绝对价格层并测试后续 3、5、10 个可见价位。

必须保存事件前每张目标订单的：

- 订单 ID；
- 剩余数量 $r_{o,e}$；
- 挂单年龄；
- 价格距离；
- 同价位排队位置或前方数量；
- 事件前是否已有部分成交；
- 事件前盘口可见性。

大单出现后新增的深档订单不进入 $\mathcal O_e^{deep}$。

## 8. 反应窗口与大单持续性

### 8.1 时间窗口

建议同时研究自然时间和事件时间：

| 口径 | 参数建议 | 用途 |
|---|---|---|
| 自然时间 | 100ms、500ms、1s、5s、30s | 衡量真实反应速度 |
| 事件时间 | 20、100、500 个后续事件 | 缓解股票活跃度差异 |

主因子建议使用 1 秒窗口，并用 500 个事件窗口做稳健性对照。若数据时间精度不足，不应使用小于时间戳精度的窗口。

### 8.2 大单持续性

若可跟踪触发订单，定义其窗口内平均剩余比例：

\[
P_e(h)
=
\frac{1}{h}
\int_{t_e}^{t_e+h}
\min\left(
\frac{R_e(u)}{q_e},1
\right)du
\]

其中 $R_e(u)$ 是触发大单或大单片段在时点 $u$ 的剩余数量。$P_e(h)\in[0,1]$：越接近 1，表示大单越持久。

辅助指标包括：

```text
large_order_lifetime
large_order_remaining_ratio_h
large_order_cancel_ratio_h
large_order_trade_ratio_h
```

被成交消耗和主动撤销具有不同含义，必须分开记录。

## 9. 事件级核心指标

### 9.1 深档既有订单撤单率

对事件 $e$ 和窗口 $h$，定义：

\[
C_e^{deep}(h)
=
\frac{
\sum_{o\in\mathcal O_e^{deep}}
CancelQty_o(t_e,t_e+h]
}{
\sum_{o\in\mathcal O_e^{deep}}r_{o,e}
+\varepsilon
}
\]

该指标只累计事件前已有剩余量的后续撤销。若订单部分成交后再撤销，只将实际撤销数量计入分子。

### 9.2 撤单订单占比

为避免少数超大深档订单主导结果，额外计算等权版本：

\[
N_e^{deep}(h)
=
\frac{
\sum_{o\in\mathcal O_e^{deep}}
\mathbf 1(CancelQty_o>0)
}{
|\mathcal O_e^{deep}|+\varepsilon
}
\]

数量加权和订单等权版本应同时输出。如果只有数量版本显著，需检查结果是否由少数大订单行为驱动。

### 9.3 距离加权撤单率

为突出大单后方最近订单，可使用：

\[
C_{e,w}^{deep}(h)
=
\frac{
\sum_o w(d_o)CancelQty_o
}{
\sum_o w(d_o)r_{o,e}+\varepsilon
},
\qquad
w(d)=e^{-\kappa(d-1)}
\]

该版本用于检验距离衰减，不建议替代无权主版本。

### 9.4 撤单强度

固定窗口撤单率会受订单提前成交影响。可进一步计算在险量口径：

\[
H_e^{cancel}(h)
=
\frac{
\sum_o CancelQty_o(t_e,t_e+h]
}{
\int_{t_e}^{t_e+h}
\sum_o R_o(u)\,du+\varepsilon
}
\]

其单位近似为单位存量、单位时间的撤单强度，适合不同窗口之间比较。

### 9.5 成交与触价结果

为验证“成交概率预期下降”渠道，同时输出：

```text
deep_existing_trade_rate_h
deep_existing_order_fill_share_h
deep_price_level_touch_rate_h
deep_cancel_to_trade_ratio_h
```

撤单风险上升且成交或触价风险下降，比单独观察撤单量更能支持遮挡机制。

## 10. 异常撤单响应

原始撤单率受订单年龄、价格距离、波动和盘口更新速度影响，不能直接作为最终因子。

### 10.1 预期撤单模型

使用历史样本或滚动训练样本估计：

\[
\widehat C_e^{base}(h)
=
E\left[
C_e^{deep}(h)\mid X_e^{pre}
\right]
\]

其中 $X_e^{pre}$ 只能包含触发前已知变量：

- 股票、日期和日内时段；
- 买卖方向；
- 目标订单总量、订单数和平均年龄；
- 各目标订单距触发价的 tick 数；
- 事件前点差、各档深度和订单数；
- 事件前短窗成交量、撤单量、订单流不平衡；
- 事件前短期收益和实现波动率；
- 距离涨跌停的 tick 数；
- 股票历史撤单率和消息到达强度。

异常撤单响应为：

\[
ACR_e(h)
=
C_e^{deep}(h)-\widehat C_e^{base}(h)
\]

可以用线性模型、分桶匹配、梯度提升树或订单级离散时间风险模型估计。第一版优先使用可解释的分桶匹配或带固定效应的线性模型。

### 10.2 不应放入主模型的变量

触发后的价格变化、成交量和订单流可能本身就是大单造成的结果。若把这些变量作为主模型控制项，会产生后处理偏误。

建议：

- 主模型只控制事件前状态，估计总反应；
- 机制分解时另建“报价未变样本”和“价格发生变化样本”；
- 对最优价改变、触发大单消失和深档成交分别做路径归因，而非全部塞入同一个回归。

## 11. 日频因子

令事件方向符号为：

\[
d_e=
\begin{cases}
+1,& \text{买侧近端大单}\\
-1,& \text{卖侧近端大单}
\end{cases}
\]

事件权重使用截尾后的规模冲击：

\[
w_e=\min(Z_e^{size},Q_{99}(Z^{size}))
\]

日内没有有效事件时因子记为缺失，不建议直接填 0。

### 11.1 DR01：无方向遮挡响应强度

\[
DR01_{i,d}
=
\frac{\sum_e w_e ACR_e(h)}{\sum_e w_e}
\]

字段名建议：`deep_cancel_response_intensity`

含义：当天两侧近端大单平均引发多强的异常深档撤单反应。该指标首先是流动性更新和不稳定性变量，优先检验未来波动率、价差及价格跳跃，而不是预设收益方向。

### 11.2 DR02：买卖侧方向性遮挡响应

\[
DR02_{i,d}
=
\frac{\sum_e w_e d_e ACR_e(h)}{\sum_e w_e}
\]

字段名建议：`deep_cancel_response_direction`

正值表示买侧近端大单引发的深档响应更强，负值表示卖侧更强。该指标混合了大单可信度与同侧深度退出，收益方向不确定，需与大单持续性联合解释。

### 11.3 DR03：持续大单可信度方向

\[
DR03_{i,d}
=
\frac{
\sum_e w_e d_e ACR_e(h)P_e(h)
}{
\sum_e w_e
}
\]

字段名建议：`persistent_large_order_credibility`

预期解释：

- 正值高：持续性买侧大单获得较强深档行为响应；
- 负值低：持续性卖侧大单获得较强深档行为响应。

该指标最接近“其他订单是否相信近端大单会持续”的行为代理。

### 11.4 DR04：大单消失后的流动性空洞方向

\[
DR04_{i,d}
=
-\frac{
\sum_e w_e d_e ACR_e(h)\left[1-P_e(h)\right]
}{
\sum_e w_e
}
\]

字段名建议：`vanishing_large_order_liquidity_gap`

前面的负号表示：

- 买侧深档撤走且近端买单消失，对后续价格偏空；
- 卖侧深档撤走且近端卖单消失，对后续价格偏多。

严格版本可以只选择“因主动撤单而消失”的近端大单，排除因成交耗尽的样本。

### 11.5 DR05：遮挡撤单弹性

在股票日内使用全部候选被动新增事件，而非只保留大单，估计剂量关系：

\[
ACR_e(h)
=
\alpha_{i,d}
+\beta_{i,d}Z_e^{size}
+\gamma^\top X_e^{pre}
+\epsilon_e
\]

定义：

\[
DR05_{i,d}=\widehat\beta_{i,d}
\]

字段名建议：`deep_cancel_shielding_elasticity`

若单日事件数不足，改用 5 日或 20 日滚动估计。该指标比硬阈值版本连续，但对样本量和模型设定更敏感。

## 12. 识别与去混淆

### 12.1 价格换档

买一卖一变化后，原买二可能显示为买三，但订单本身没有撤销。必须按订单 ID 和绝对价格跟踪，不能根据档位编号的消失判断撤单。

主机制检验应优先使用：

- 触发订单在原有价格层扩量；
- 反应窗口内最优报价未变化的样本；
- 目标订单始终位于可观察深度内的样本。

### 12.2 大单与共同信息冲击

近端大单和深档撤单可能共同响应价格信号，而非前者导致后者。建议使用三类对照：

1. 相同股票、时段、点差、深度、收益和消息强度下的小单新增事件；
2. 同一事件的对侧、相同距离既有订单；
3. 同侧大单出现前的撤单率或匹配的无大单时点。

可使用差分中的差分：

\[
\Delta C
=
(C_{same,post}-C_{same,pre})
-(C_{opp,post}-C_{opp,pre})
\]

再比较大单事件与匹配小单事件的 $\Delta C$。但对侧也可能受到信息冲击，不能将其视为完美反事实，只能作为辅助识别。

### 12.3 成交导致的撤单竞争风险

订单一旦成交就无法继续撤销，成交与撤单是竞争风险。建议同时估计：

- 撤单原因风险；
- 成交原因风险；
- 订单仍存续概率；
- 价格层触达概率。

若只看最终撤单比例，可能把“成交减少后留下更多可撤订单”误判为主动撤单意愿上升。

### 12.4 大单被成交与大单主动撤销

大单剩余量下降可能有两种路径：

- 被主动成交消耗：说明对手方需求强；
- 大单自身撤销：说明流动性供给撤回。

两者对价格含义不同。DR03 和 DR04 必须分路径报告，尤其不能把被成交耗尽的大买单简单归为“虚假支撑消失”。

### 12.5 重叠窗口与重复计数

同一目标订单可能被多个连续大单遮挡，同一撤单也可能落入多个反应窗口。主版本通过事件片段和冷却期解决；稳健性版本可使用：

- 只保留每个片段第一笔大单；
- 只保留窗口内没有第二次触发的事件；
- 将撤单量按重叠事件数分摊。

## 13. 实证检验方案

### 13.1 机制事件研究

以大单出现时点为 0，计算 $[-5s,+30s]$ 内同侧深档撤单强度，按 100ms 或 500ms 分桶。分别画出：

- 大单事件；
- 匹配小单事件；
- 同侧目标订单；
- 对侧同距离订单；
- 高持续性与低持续性大单。

首先确认撤单反应发生在事件后，而非事件前已经上升。

### 13.2 订单级风险模型

对每张目标订单构建离散时间面板：

\[
P(Cancel_{o,u}=1)
=
g\left(
\alpha
+\beta_1 LargeShock_e
+\beta_2 Post_u
+\beta_3 LargeShock_e\times Post_u
+\theta^\top X_{o,e}^{pre}
\right)
\]

核心参数为 $\beta_3$。标准误至少按股票日聚类；大样本下可按股票和日期双向聚类。

另建同结构的成交风险模型。支持机制的理想结果是：

```text
大单后撤单风险上升
大单后成交或触价风险下降
效应随大单规模和持续性增强
效应在事件前不存在
```

### 13.3 日频横截面测试

对 DR01—DR05 分别检验：

- 下一交易日开盘到收盘、开盘到 VWAP、VWAP 到 VWAP 收益；
- 未来 1、2、5、10 日收益；
- 未来实现波动率、振幅、价差和跳跃概率；
- 换手率、盘口深度和流动性恢复速度。

收益测试至少控制：

- 当日收益和短期反转；
- 波动率、振幅和换手率；
- 市值、价格、流动性和行业；
- 普通盘口不平衡；
- 大单净流入、委托冲击和成交冲击；
- 原始撤单率和订单消息强度。

重点检查本因子相对于“大单方向 × 普通撤单率”的增量，而不是只报告单因子 IC。

### 13.4 分组检验

建议按以下维度分组：

- 大单规模分位；
- 大单持续性；
- 距离大单的 tick 数；
- 原价扩量与价差内改善；
- 低波动与高波动时段；
- 高主动交易强度与低主动交易强度；
- 大盘股与小盘股；
- 普通交易日与涨跌停附近交易日。

## 14. 安慰剂与稳健性检验

### 14.1 安慰剂

- 用未来 1—5 秒才出现的大单解释当前撤单，系数不应呈现同样的事件后形态；
- 随机打乱事件方向，效果应明显减弱；
- 用普通小单替代大单，反应应更弱并具有规模单调性；
- 用同价位排在新增大单之前的既有订单作为安慰剂，理论上不应出现相同遮挡效应；
- 在最优报价、短期收益和主动流量均稳定的子样本中重复检验。

### 14.2 参数稳健性

至少测试：

| 参数 | 主版本 | 稳健性范围 |
|---|---:|---:|
| 近端档位 $K$ | 2 | 1、2、3 |
| 深档范围 $J$ | 5 ticks | 3、5、10 ticks |
| 大单分位 | 95% | 90%、97.5%、99% |
| 相对深度阈值 | 1 倍 | 0.5、1、2 倍 |
| 反应窗口 | 1 秒 | 100ms、500ms、5s、30s |
| 冷却期 | 500ms | 100ms、1s、事件数窗口 |
| 历史窗口 | 20 日 | 10、40、60 日 |

如果结论只在单一参数下出现，应降低因子优先级。

## 15. 计算流程

### 15.1 严格版本伪代码

```text
for each symbol, trade_date:
    sort events by event_time, event_seq
    initialize order_state and order_book

    for event in events:
        pre_book = current order_book

        if event is passive new order:
            classify near level and trigger type
            compute lagged size percentile and relative depth

            if event qualifies as a large-order trigger:
                capture all pre-existing same-side orders
                strictly worse than trigger price
                and within J ticks

                create or update non-overlapping large-order episode

        update order_state and order_book using current event

        for each active episode:
            attribute trades and cancellations only to captured orders
            update trigger-order remaining quantity and persistence
            close episode when horizon expires

    calculate raw cancellation, fill, touch and persistence metrics
    estimate or join expected cancellation rate from lagged model
    calculate event-level abnormal response
    aggregate non-overlapping events to daily DR01-DR05
```

### 15.2 快照近似版本

在相邻快照中，只对价格未变化且仍可见的绝对价位计算深度减少：

```text
deep_net_loss = max(pre_existing_depth - surviving_depth - trade_depletion, 0)
```

然后用事件前深档深度标准化。任何移出可见档位、价格跳变或成交无法连接的区间应标记为低可信样本，不强行推断撤单。

## 17. 质量控制

每日检查：

1. 事件是否按统一序号严格排序；
2. 订单剩余量是否出现负值；
3. 撤单量与成交量之和是否超过原始订单量；
4. 目标集合是否只包含事件前已存在订单；
5. 目标订单价格是否严格劣于触发价格；
6. 同价位早到订单是否被错误纳入；
7. 快照换档是否被误判为撤单；
8. 同一次撤单是否被重复归因；
9. 历史大单阈值是否完全滞后；
10. 无触发事件和数据缺失是否被错误填为 0；
11. 大单被成交与主动撤销是否分开；
12. 集合竞价、休市和封板状态是否正确过滤。

建议设置股票日级最低质量门槛：

```text
order_link_rate >= 99%
valid_large_order_episode_count >= 3
valid_target_order_count >= 20
overlap_event_share <= 20%
```

具体阈值根据数据源覆盖情况调整，并保留未过滤版本用于诊断。

## 18. 推荐实施顺序

### 第一阶段：确认机制

1. 只用 A 类“原价扩量”事件；
2. 只用窗口内最优报价不变的样本；
3. 使用订单 ID 锁定事件前既有深档订单；
4. 比较大单、小单及事件前后的撤单和成交风险；
5. 验证规模、距离和持续性的单调关系。

### 第二阶段：构造基础因子

6. 计算 DR01 无方向响应强度；
7. 计算 DR02 买卖侧方向差；
8. 控制普通撤单率、大单流入和盘口不平衡，检查增量。

### 第三阶段：引入大单生命周期

9. 将大单剩余量变化拆成被成交与主动撤销；
10. 计算 DR03 可信度方向；
11. 计算 DR04 流动性空洞方向；
12. 检验价格跳变、反转和流动性恢复路径。

### 第四阶段：扩展与上线评估

13. 加入 B 类价差内改善事件；
14. 实现滚动遮挡弹性 DR05；
15. 做样本外、分市场状态和交易成本检验；
16. 只有在增量稳定后，才进入正式因子池。

## 19. 最小可行版本

如果希望先快速判断研究是否值得继续，建议采用以下最小版本：

```text
触发：买一/卖一原价新增被动订单，规模位于过去 20 日同股票同侧前 5%
目标：事件前已存在、同侧、后方 1-5 ticks 的订单
窗口：1 秒
响应：目标订单撤单量 / 事件前目标订单剩余量
过滤：窗口内最优报价不变；事件窗口不重叠
对照：相同盘口状态下 40%-60% 规模分位的普通新增订单
验证：撤单率差、成交率差、事件前趋势、规模单调性
聚合：买侧异常响应减卖侧异常响应；再与大单持续性相乘
```

最小版本若不能同时观察到“撤单风险提高、成交或触价风险下降、效应随规模增强”，则不宜直接进入复杂因子优化，应先重新检查机制或数据口径。

## 20. 结论

本因子的关键不是简单统计“大单之后深档撤了多少”，而是识别：

\[
\boxed{
\text{近端异常被动流动性新增}
\rightarrow
\text{同侧深档既有订单成交机会下降}
\rightarrow
\text{异常撤单响应}
}
\]

可实现性的核心条件有三个：

1. 按订单身份和绝对价格跟踪事件前既有订单；
2. 将真实撤单与成交、价格换档和可见档位移出区分开；
3. 将深档响应与近端大单的持续、被成交和主动撤销路径联合建模。

在这一基础上，DR01 描述流动性行为强度，DR03 描述市场对持续大单的行为认可，DR04 描述大单消失后可能形成的流动性空洞。三者应分别检验，不应预先压缩成一个含义不清的总因子。
