# 量比与订单行为因子手册

## 1. 文档目的

本文档将“成交量相对于被动委托量更有弹性”的研究发现，整理为可复现、可回测、可移交实现的因子规范。

手册覆盖：

- 原始研究口径的复现；
- 基础日频因子及扩展因子；
- 日内版本；
- 数据依赖与订单分类；
- 回测、风格控制和稳健性检验；
- 输出字段与质量检查。

本文档中的“量”默认指股数或合约数量，不是成交金额。若使用成交金额，应另建一组因子并明确命名。

## 2. 研究假说

原始研究的主要发现是：

1. 成交量与被动委托量之比越高，股票当日换手率和振幅通常越高。
2. 将“量”替换为“笔数”后，上述关系明显减弱。
3. 交易热度上升时，成交量增长得比被动委托量更快；成交主动方笔数与被动委托笔数的增长速度则较接近。
4. 因此，有效信息可能主要来自单笔成交规模，而不是交易次数。
5. 高量比、大单行为和价格波动倾向于同时出现，但不能仅凭相关性认定“大单导致波动”。

由此得到三个可检验假说：

- `H1`：无方向量比主要预测未来交易热度、振幅和波动率。
- `H2`：量比相对记数比的增量，能够刻画主动成交规模相对被动流动性供给的异常放大。
- `H3`：加入买卖方向、盘口状态和价格路径后，可以区分信息型冲击与临时流动性冲击。

## 3. 样本与交易阶段

### 3.1 基础样本过滤

建议剔除：

- 停牌股票；
- ST、`*ST` 股票；
- 上市不足 10 个交易日的股票；
- 连续涨停或跌停封板时间过长的股票；
- 数据明显缺失或事件顺序异常的股票；
- 集合竞价阶段。

若用于真实组合，还应增加最低成交额、最低交易天数和可交易状态过滤。

### 3.2 交易阶段

原始口径仅使用连续竞价阶段。集合竞价中的订单同时累积并统一撮合，无法自然划分主动方和被动方，不应与连续竞价混合。

午间休市前后应分别维护订单簿状态，不得把休市期间误判为无交易异常。

## 4. 数据要求

### 4.1 核心字段

逐笔委托至少需要：

| 字段 | 含义 |
|---|---|
| `symbol` | 证券代码 |
| `trade_date` | 交易日 |
| `event_time` | 交易所时间 |
| `event_seq` | 交易所事件序号，优先级高于时间戳 |
| `order_id` | 委托编号 |
| `side` | 买入或卖出 |
| `order_price` | 委托价格 |
| `order_qty` | 原始委托数量 |
| `order_type` | 限价、市价或其他订单类型 |

| 字段 | 含义 |
|---|---|
| `trade_id` | 成交编号 |
| `trade_time` | 成交时间 |
| `trade_seq` | 成交或统一事件序号 |
| `trade_price` | 成交价格 |

| 字段 | 含义 |
|---|---|
| `order_id` | 被撤委托编号 |
| `cancel_time` | 撤单时间 |
| `cancel_seq` | 撤单事件序号 |
| `cancel_qty` | 撤单数量 |

### 4.2 数据依赖分层

| 层级 | 数据能力 | 可实现内容 |
|---|---|---|
| A | 逐笔成交、双方订单号、主动方标记 | 主动成交量、主动订单笔数、大单成交占比 |
| B | A + 逐笔委托 + 严格事件顺序 | 原始量比、记数比、单笔规模差异 |
| C | B + 撤单 + 最优买卖价重建 | 方向性量比、价差条件化、撤单率 |
| D | C + 全深度订单簿 | 多档深度消耗、冲击成本、流动性恢复 |

复现原始量比和记数比至少需要 B 层。涉及盘口深度和恢复过程的扩展因子需要 C 或 D 层。

## 5. 主动与被动委托定义

### 5.1 基础定义

在连续竞价阶段：

- 委托进入市场后立即与已有订单成交，定义为主动委托；
- 委托进入后没有立即成交，而是留在订单簿中等待后续撮合，定义为被动委托。

限价单不必然是被动委托。可成交限价单虽然具有价格上限或下限，但只要进入后立即成交，就属于主动委托。

### 5.2 主动方判断顺序

主动方识别优先级：

1. 使用交易所或数据商提供的主动方标记；
2. 使用买卖双方订单号和订单事件顺序识别后到订单；
3. 使用成交前最优买卖价识别；
4. 最后才使用成交价相对中间价的规则近似。

仅使用成交价规则会在价差内成交、行情延迟和报价跳变时产生误判。

### 5.2.1 沪市立即成交与订单簿触发

在当前 `event_full_depth_v3` 数据中，沪市可成交订单即使没有先产生
`ORDER_ADD`，每笔立即成交仍会产生一行 `source_action = 'TRADE'` 的订单簿
触发记录。该行全深度快照表示该笔撮合完成后的订单簿状态；一张主动订单连续
撮合多张被动订单时，会产生连续多行 `TRADE` 触发的成交后快照。

因此，沪市提前撮合并不表示撮合过程未反映在订单簿数据中。可能缺失或延后的是
主动订单自身的 `ORDER_ADD`：若订单完全立即成交，可能没有 `ORDER_ADD`；若有
未成交余量，余量可能在若干 `TRADE` 之后才以 `ORDER_ADD` 发布。计算量比时应
直接从 `TRADE` 触发行统计成交量和主动订单，并将后续同一主动订单 ID 的
`ORDER_ADD` 识别为主动订单余量，不得计入被动委托分母。

### 5.3 分拆成交计数

一张主动订单可能连续吃掉多张被动订单，形成多条成交记录。主动方笔数必须按照主动订单编号去重。

示例：

| 成交记录 | 主动订单号 | 被动订单号 |
|---|---|---|
| 1 | A100 | S201 |
| 2 | A100 | S202 |
| 3 | A100 | S203 |

该例应统计为：

- 成交记录 3 条；
- 主动委托 1 笔；
- 被动委托 3 笔。

不得直接使用成交记录行数代替主动方笔数。

### 5.4 部分主动成交后的剩余量

一张可成交限价单可能先主动成交，剩余数量随后进入订单簿。

主版本建议采用“订单到达分类”：

- 只要到达后立即发生成交，整张订单计为一笔主动委托；
- 未立即成交的订单计为一笔被动委托；
- 主动订单成交后的剩余挂单不进入原始被动委托分母。

同时应实现一个敏感性版本“数量切片分类”：

- 立即成交部分计为主动数量；
- 剩余进入订单簿的数量计为被动数量；
- 笔数口径仍需单独规定，不与主版本混用。

两个版本分别输出，检验结论是否依赖分类边界。该问题正是作者结尾提出的“主动性并非跳变”的一部分。

## 6. 日频聚合变量

对股票 \(i\)、交易日 \(t\)，在连续竞价阶段定义：

| 符号 | 字段名建议 | 定义 |
|---|---|---|
| \(Q_{i,t}\) | `trade_qty` | 全部成交量之和 |
| \(A_{i,t}\) | `aggr_order_count` | 主动方订单编号去重数 |
| \(P_{i,t}\) | `passive_submit_qty` | 被动委托原始提交量之和 |
| \(M_{i,t}\) | `passive_order_count` | 被动委托编号去重数 |
| \(Q^B_{i,t}\) | `aggr_buy_qty` | 主动买入成交量 |
| \(Q^S_{i,t}\) | `aggr_sell_qty` | 主动卖出成交量 |
| \(A^B_{i,t}\) | `aggr_buy_count` | 主动买订单数 |
| \(A^S_{i,t}\) | `aggr_sell_count` | 主动卖订单数 |
| \(P^B_{i,t}\) | `passive_bid_qty` | 被动买委托量 |
| \(P^A_{i,t}\) | `passive_ask_qty` | 被动卖委托量 |

注意：\(P\) 是被动委托的原始提交量，不是被动方实际成交量。若分母使用实际被动成交量，则它与总成交量机械相等，无法形成原始研究中的量比。

## 7. 核心日频因子

### 7.1 原始量比

\[
VR_{i,t}=\frac{Q_{i,t}}{P_{i,t}}
\]

字段名：`vr_raw`

经济含义：当日成交量相对于新增被动流动性供给的比例。

在严格分类、连续竞价和数据完整的情况下，原始研究认为该值通常不超过 1。超过 1 时需要检查：

- 集合竞价订单是否混入；
- 跨交易阶段订单是否遗漏；
- 被动委托是否少计；
- 主动订单剩余挂单的处理；
- 数据商订单号和撤单规则。

超过 1 不应直接截断，应先作为质量异常分析。

### 7.2 原始记数比

\[
CR_{i,t}=\frac{A_{i,t}}{M_{i,t}}
\]

字段名：`cr_raw`

经济含义：主动成交订单笔数相对于被动委托笔数的比例。

该值可以超过 1。高记数比可能来自主动交易活跃，也可能来自主动订单平均规模较小，因此不必然代表高成交热度。

### 7.3 对数版本

为降低偏态和极端值影响，建模时建议同时输出：

\[
LVR_{i,t}=\log(Q_{i,t}+\epsilon_Q)-\log(P_{i,t}+\epsilon_P)
\]

\[
LCR_{i,t}=\log(A_{i,t}+\epsilon_A)-\log(M_{i,t}+\epsilon_M)
\]

字段名：`vr_log`、`cr_log`

日频数据充分时，优先在分母为零的样本上设为缺失，而不是依靠任意常数修复。平滑常数只用于明确的稀疏数据版本，并需要记录具体取值。

### 7.4 单笔规模比

原始比值：

\[
SSR_{i,t}=\frac{VR_{i,t}}{CR_{i,t}}
=
\frac{Q_{i,t}/A_{i,t}}{P_{i,t}/M_{i,t}}
\]

对数版本：

\[
LSSR_{i,t}=LVR_{i,t}-LCR_{i,t}
\]

字段名：`single_size_ratio`、`single_size_ratio_log`

经济含义：平均主动成交规模相对于平均被动委托规模的大小。

原始研究提示该指标可能是负向收益因子，但全天不加筛选时容易被传统风格解释，因此不能预设收益方向，应在样本外检验。

### 7.5 历史排名与异常度

20 日时间序列排名：

\[
VRRank20_{i,t}
=
\operatorname{PercentileRank}
\left(
VR_{i,t};
VR_{i,t-19:t}
\right)
\]

20 日历史标准分：

\[
VRZ20_{i,t}
=
\frac{
LVR_{i,t}-\mu(LVR_{i,t-20:t-1})
}{
\sigma(LVR_{i,t-20:t-1})
}
\]

字段名：`vr_rank_20d`、`vr_z_20d`

排名版本用于复现原始分组现象；标准分版本保留异常程度。标准分的历史均值和波动率不得包含当天。

记数比和单笔规模比应构造对应版本。

### 7.6 成交量弹性

按照原始研究定义：

\[
\sigma^Q_{i,t}
=
\operatorname{STD}_{k=1,\ldots,T}
\left[
\log(Q_{i,t-k})
\right]
\]

\[
\sigma^P_{i,t}
=
\operatorname{STD}_{k=1,\ldots,T}
\left[
\log(P_{i,t-k})
\right]
\]

\[
ElasticityQty_{i,t}
=
\log\frac{\sigma^Q_{i,t}}{\sigma^P_{i,t}}
\]

字段名：`qty_elasticity_20d`

对应笔数版本：

\[
ElasticityCount_{i,t}
=
\log
\frac{
\operatorname{STD}[\log(A)]
}{
\operatorname{STD}[\log(M)]
}
\]

二者差异：

\[
ElasticityGap_{i,t}
=
ElasticityQty_{i,t}-ElasticityCount_{i,t}
\]

字段名：`count_elasticity_20d`、`elasticity_gap_20d`

主窗口建议为 20 日，稳健性窗口使用 10、40、60 日。

## 8. 扩展日频因子

### 8.1 方向性流动性消耗

\[
DSP_{i,t}
=
\log\frac{Q^B_{i,t}+\epsilon}{P^A_{i,t}+\epsilon}
-
\log\frac{Q^S_{i,t}+\epsilon}{P^B_{i,t}+\epsilon}
\]

字段名：`directional_size_pressure`

高值表示主动买入相对于卖盘被动供给更强，低值表示主动卖出相对于买盘被动供给更强。

无方向量比更适合预测波动，方向性压力更适合预测收益方向。

### 8.2 大单主动成交占比

先按股票自身历史分布定义大单，例如过去 20 日主动订单成交量的 90% 分位：

\[
LargeShare_{i,t}
=
\frac{
\sum \text{大额主动订单成交量}
}{
Q_{i,t}
}
\]

字段名：`large_aggr_trade_share`

阈值必须滞后计算，不得使用当天或未来成交确定当天的大单标准。

### 8.3 大单相对被动供给

\[
LargePressure_{i,t}
=
\frac{
\sum \text{大额主动订单成交量}
}{
P_{i,t}
}
\]

字段名：`large_aggr_to_passive_qty`

### 8.4 分时段量比

分别计算：

- 开盘后 30 分钟；
- 上午剩余时段；
- 下午非尾盘时段；
- 收盘前 30 分钟。

字段名示例：

- `vr_open_30m`
- `vr_morning_rest`
- `vr_afternoon`
- `vr_close_30m`

同时构造时段差：

\[
VRCloseMinusOpen_{i,t}
=
LVR^{close}_{i,t}-LVR^{open}_{i,t}
\]

分时段因子可以减少全天混合不同交易动机的问题，并用于识别开盘信息释放、日内机构执行和尾盘冲击。

### 8.5 盘口条件化压力

需要重建盘口：

\[
DepthPressure_{i,t}
=
\frac{
\text{主动成交量}
}{
\text{事件前多档盘口平均深度}
}
\]

字段名：`aggr_to_depth`

进一步加入相对价差：

\[
FragilePressure_{i,t}
=
DepthPressure_{i,t}\times RelativeSpread_{i,t}
\]

字段名：`fragile_pressure`

该指标刻画主动成交强、盘口薄且价差大的脆弱状态。

### 8.6 单位成交量价格冲击

\[
PriceImpact_{i,t}
=
\frac{
|\Delta MidPrice_{i,t}|
}{
Q_{i,t}/FloatShares_{i,t}
}
\]

字段名：`price_impact_per_turnover`

建议同时输出有方向和无方向版本，并控制当日波动率与价差。

### 8.7 冲击后的价格修复

识别大额主动订单事件 \(e\)，计算：

\[
ImmediateImpact_e
=
Side_e
\times
\left(
\log Mid_{e+\Delta_1}-\log Mid_{e-}
\right)
\]

\[
PostMove_e
=
Side_e
\times
\left(
\log Mid_{e+\Delta_2}-\log Mid_{e+\Delta_1}
\right)
\]

其中买入方向取 \(Side=1\)，卖出方向取 \(Side=-1\)。

- `PostMove > 0`：冲击后延续；
- `PostMove < 0`：冲击后反转或修复。

按日聚合事件均值、中位数和大额成交加权均值。

## 9. 日内因子版本

### 9.1 计算频率

推荐基准配置：

- 每 5 分钟更新一次；
- 回看窗口使用 5、15、30、60 分钟；
- 形成信号后至少延迟 1 分钟成交；
- 预测未来 5、15、30、60 分钟。

### 9.2 日内量比

对回看窗口 \(W\)：

\[
LVR^{W}_{i,t}
=
\log(Q^{W}_{i,t}+\epsilon)
-
\log(P^{W}_{i,t}+\epsilon)
\]

### 9.3 日内记数比

\[
LCR^{W}_{i,t}
=
\log(A^{W}_{i,t}+\epsilon)
-
\log(M^{W}_{i,t}+\epsilon)
\]

### 9.4 日内单笔规模差异

\[
LSSR^{W}_{i,t}
=
LVR^{W}_{i,t}-LCR^{W}_{i,t}
\]

### 9.5 同时段标准化

日内成交和委托具有显著 U 形季节性。当前时点只能与过去交易日的相同时段比较：

\[
IntradayZ_{i,t}
=
\frac{
F_{i,t}-\mu(F_{i,\text{过去20日相同时段}})
}{
\sigma(F_{i,\text{过去20日相同时段}})
}
\]

不得使用当日完整日内分布对当日早盘信号进行标准化。

### 9.6 日内预测目标

无方向因子主要测试：

\[
FutureRV_{i,t,h}
=
\sum_{j=t+1}^{t+h}r_{i,j}^{2}
\]

\[
FutureAbsRet_{i,t,h}
=
|\log Mid_{i,t+h}-\log Mid_{i,t}|
\]

方向性因子主要测试：

\[
FutureRet_{i,t,h}
=
\log Mid_{i,t+h}-\log Mid_{i,t}
\]

还应测试冲击方向上的延续与反转。

## 10. 实现流程

### 10.1 事件处理

对每只股票、每个交易日：

1. 按 `event_seq` 排序；没有统一事件序号时，使用交易所规定的事件优先级。
2. 初始化订单簿和订单状态表。
3. 处理新委托，记录到达前买一、卖一和盘口深度。
4. 根据交易所标记或是否立即成交判断主动性。
5. 处理一张主动订单拆分产生的多条成交，不重复计算主动笔数。
6. 更新被动订单的剩余数量和成交状态。
7. 处理部分撤单和全部撤单。
8. 排除集合竞价和异常交易阶段。
9. 按日及分时段聚合基础变量。
10. 计算因子，并输出质量检查字段。

### 10.2 建议维护的订单状态

每个 `order_id` 至少维护：

- 到达时间与事件序号；
- 买卖方向；
- 原始价格和数量；
- 是否到达即成交；
- 主动或被动分类；
- 累计成交量；
- 累计撤单量；
- 当前剩余量；
- 首次成交时间；
- 最后成交或撤单时间。

应满足：

\[
原始委托量
=
累计成交量
+
累计撤单量
+
期末剩余量
\]

允许交易所特殊规则造成的例外，但必须记录异常比例。

## 11. 因子输出规范

每行建议为“股票 × 信号日期 × 因子版本”。

基础字段：

| 字段 | 说明 |
|---|---|
| `symbol` | 证券代码 |
| `trade_date` | 因子形成日期 |
| `signal_time` | 日内因子形成时点；日频为空或收盘后 |
| `factor_name` | 因子名称 |
| `factor_value_raw` | 原始值 |
| `factor_value_winsor` | 去极值后的值 |
| `factor_value_z` | 标准化值 |

## 12. 日频回测规范

### 12.1 时间顺序

若使用第 \(t\) 日完整数据构造因子，信号只能在第 \(t\) 日收盘后获得。

基准交易设置：

- \(t\) 日收盘后形成信号；
- \(t+1\) 日开盘后成交，基准价格使用开盘后 30 分钟 VWAP；
- 分别持有 1、2、5、10 个交易日；
- 使用后复权价格计算收益；
- 不得假设以 \(t\) 日收盘价成交。

可增加次日开盘价、次日全天 VWAP 等版本作为执行敏感性检验。

### 12.2 单因子检验

每日计算横截面 Spearman IC：

\[
IC_t
=
\operatorname{corr}_{rank}
\left(
F_{i,t},R_{i,t+1:t+h}
\right)
\]

报告：

- IC 均值、中位数和标准差；
- ICIR；
- IC 正负比例；
- 年度和市场状态分组结果；
- 1、2、5、10 日衰减；
- 收益、绝对收益、振幅和实现波动率四类目标。

量比对未来收益不显著，并不意味着因子无效；它可能主要是未来波动率因子。

### 12.3 分组回测

每日按因子分为 5 组或 10 组，检查：

- 分组收益是否单调；
- 高组减低组和低组减高组；
- 多头端、空头端贡献；
- 换手率和组合容量；
- 行业及风格暴露；
- 成本前后收益。

不应根据全样本结果反向选择因子方向。因子方向应在训练期确定，在验证期保持不变。

### 12.4 交易成本

至少测试：

- 单边 5、10、20 个基点；
- 半个买卖价差；
- 手续费和税费；
- 成交冲击；
- 涨跌停和停牌造成的无法成交；
- 延迟成交和组合容量限制。

## 13. 日内回测规范

### 13.1 严格时间线

\[
历史事件窗口
\rightarrow
t\text{ 时点形成信号}
\rightarrow
\text{延迟成交}
\rightarrow
\text{未来收益或波动}
\]

理论成交价优先使用：

- 下一分钟 VWAP；
- 延迟后的买一或卖一；
- 加入半价差和冲击成本后的模拟成交价。

不得使用形成信号的最后一笔成交价作为无成本可成交价格。

### 13.2 重叠样本

每 5 分钟产生信号并预测未来 30 分钟，会形成重叠样本并夸大显著性。

主检验应使用非重叠区间，重叠样本作为辅助，并对统计量进行时间相关性修正。

### 13.3 信号衰减

分别测试延迟 0、1、3、5、10 分钟后的表现。若延迟 1 分钟后信号消失，它更可能是同步盘口关系，而不是可实现的预测信号。

## 14. 风格暴露与重复性

候选因子可能与以下风格重复：

| 候选因子 | 主要潜在重复风格 |
|---|---|
| 量比 | 换手率、成交活跃度、流动性、波动率 |
| 记数比 | 换手率、小盘、交易活跃度 |
| 单笔规模比 | 大单交易、机构交易、小盘、流动性 |
| 量比异常度 | 异常换手、成交量冲击、短期反转 |
| 成交量弹性 | 成交量波动率、价格波动率、投机程度 |
| 方向性压力 | 订单失衡、资金流、短期动量 |
| 盘口条件化压力 | Amihud 非流动性、价差、尾部风险 |
| 价格冲击 | 非流动性、波动率、短期反转 |

每日可做横截面残差化：

\[
F_{i,t}
=
\alpha_t
+
\beta_1\log(Size_{i,t})
+
\beta_2 Turnover_{i,t}
+
\beta_3 Volatility_{i,t}
+
\beta_4 Liquidity_{i,t}
+
\beta_5 Momentum_{i,t}
+
Industry_{i,t}
+
\varepsilon_{i,t}
\]

建议同时报告：

- 原始因子；
- 仅行业和市值中性化版本；
- 完整风格中性化版本。

不能只报告残差版本，因为换手率、流动性和波动率也可能属于因子真实机制的一部分。

还应执行双重分组：先按市值、换手率、波动率或流动性分组，再在组内按候选因子分组。

## 15. 质量检查

### 15.1 数据级检查

- 事件序号严格单调；
- 订单号和成交双方订单号可关联；
- 成交量为正；
- 买卖方向合法；
- 撤单量不超过订单剩余量；
- 订单数量守恒；
- 集合竞价没有混入；
- 股票代码和交易日无跨日串联；
- 主动订单拆分成交只计一笔；
- 因子计算未使用未来数据。

### 15.2 统计级检查

- 报告量比大于 1 的样本比例；
- 报告分母为零或过小的样本比例；
- 检查不同数据源和交易所的分布差异；
- 检查开盘、午间和尾盘附近的异常峰值；
- 检查原始值、对数值和排名值的分布；
- 检查因子与市值、股价、换手率、波动率和价差的相关性；
- 检查极端值是否集中于低价、低流动性或涨跌停股票。

## 16. 推荐研究顺序

第一阶段：复现原始事实。

1. 计算 `vr_raw`、`cr_raw`。
2. 复现它们与换手率、振幅的 20 日时序排名关系。
3. 验证被动委托量分组下量比是否递增。
4. 验证成交量滚动对数波动率是否高于被动委托量。

第二阶段：验证增量信息。

1. 计算 `single_size_ratio_log`。
2. 测试未来收益、波动率、振幅和成交活跃度。
3. 控制市值、换手率、波动率、流动性和短期收益。
4. 做双重分组与样本外检验。

第三阶段：改善经济解释。

1. 区分主动买入和主动卖出。
2. 区分开盘、盘中和尾盘。
3. 加入盘口深度和价差。
4. 研究大单冲击后的价格延续或反转。
5. 比较“订单到达分类”和“数量切片分类”。

第四阶段：日内化与可交易性。

1. 构造 5、15、30、60 分钟窗口因子。
2. 按历史相同时段标准化。
3. 测试不同预测期限与执行延迟。
4. 加入价差、冲击、容量和无法成交约束。

## 18. 实现前必须确认的口径

实现方开始编码前，应明确以下事项并写入版本说明：

1. “量”使用股数、手数还是成交金额；
2. 被动委托量使用原始提交量还是后续实际入簿量；
3. 部分主动成交后的剩余挂单如何分类；
4. 主动方由交易所标记、订单序号还是成交价规则识别；
5. 跨午间和跨交易日订单如何处理；
6. 市价单和特殊订单类型如何处理；
7. 撤单是否影响被动委托分母；
8. 大单阈值使用何种历史窗口和分位数；
9. 时间序列标准化是否严格使用 \(t-1\) 以前数据；
10. 回测成交价格、延迟、成本和不可交易规则。

任何口径变化都应提高 `factor_version`，不得覆盖旧结果。

## 19. 结果解释边界

量比、大单成交和价格波动同时上升，只能说明这些行为相伴出现。可能的机制包括：

- 大额主动成交消耗盘口并推动价格；
- 交易者预期价格变化而提前成交；
- 价格变化吸引更多交易，形成自激过程；
- 新闻或认知变化同时推动成交和价格。

因此，分组收益和相关性不能直接作为因果证据。应结合事件时间、领先滞后、盘口恢复和外生事件进行进一步判断。

本因子体系的研究目标不是证明“大单必然导致波动”，而是检验订单规模、流动性供给和价格变化之间是否存在稳定、可复现且扣除成本后仍可利用的关系。
