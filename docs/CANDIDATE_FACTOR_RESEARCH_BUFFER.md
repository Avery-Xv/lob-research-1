# 候选因子研究缓冲区

## 1. 用途与边界

本文件保存已经排除、降级或暂缓，但仍具有机制信息、控制价值或明确重启条件的候选方向。它不是正式因子注册表，也不表示这些方向可以进入生产。

- 正式候选因子状态以`research/factors.json`为准；
- 正式研究问题状态以`research/experiments.json`为准；
- 本缓冲区编号`BFRxxx`仅用于文档追踪，不是F/R/Q/P编号；
- 任何重启必须使用预先写明的新证据或修复条件，不能因为更换符号、阈值或分域而重新挖掘。

当前范围主要覆盖F014和R014–R018，以及R017收益深化中产生的派生方向。

## 3. 分类规则

### 排除

当前研究问题已经触发停止规则。除非出现不同的经济定义或真正独立的样本外证据，否则不继续调参。

### 降级

该方向仍有机制价值，但不具备独立收益因子的证据。允许作为状态、过滤器、控制变量、执行变量或新研究的对照。

### 暂缓

研究问题仍成立，但当前输入语义或工程质量不允许得出结论。必须先完成指定修复和质量门，旧结果不得恢复使用。

## 4. 维护规则

1. 新增条目必须写明证据路径、失败或阻断原因以及唯一可接受的重启条件；
2. 从缓冲区恢复时，先更新正式F/R注册表，再创建新的append-only运行；
3. 降级方向若被其他因子采用，必须明确标注是控制或状态，不得暗示其已成为alpha；
4. 暂缓方向修复后保留旧条目和失效原因，不能覆盖历史记录；
5. F018的正式候选档案位于`research/candidate_factors/F018_minus_flow_to_opponent_depth/`。
