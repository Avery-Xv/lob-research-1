# 非母单固定 10:30 全市场九分域研究结论（2026-01）

## 1. 研究范围与口径

本轮使用已审计完成的 F013/P002 固定 10:30 缓存，构造 2026 年 1 月全市场 F014 候选。候选共有 101,383 个股票日、5,133 只股票、20 个交易日。主结果是九分域内逐日横截面 Rank IC，再对九域等权聚合；全市场和沪深结果只作诊断。结果均为 raw、未中性化直接目标检验，不含未来收益标签。

九分域由前一交易日总市值三档与价格/科创属性三档交叉得到。51 行缺少前一日域数据被排除；科创板 10 元以下按预注册规则排除。

## 3. 分课题解释

### R014：成交机会惊奇

原始成交机会压力对未来主动净流仍然很强（IC = 0.0629，t = 8.98），但控制 M1、M1²、M1³ 后，方向关系变为轻微负值。历史 300 股样本中约 0.0093 的正增量没有在全市场九分域复现，因此按照预注册停止规则，不再调符号、阈值或多项式阶数挽救方向假说。

残差对未来主动成交量仍为正（IC = 0.0270，t = 6.98，8/9 域为正），说明它更像“即将活跃”的状态，而不是买卖方向因子。对因子研究的启示是：预测成交机会与预测方向必须分开；不能把可成交性状态直接当作收益方向。

### R015：总体可成交性

在控制当前主动量/笔数、历史样本数、价差和深度后，可成交性残差仍显著预测未来主动量、事件数和实现波动。它对未来实现波动 IC = 0.0694（t = 17.72，8/9 域为正），同时对应点差下降和深度下降，而不是简单的“流动性恶化”。

这更适合作为活动度、波动和容量状态变量，可用于条件化其他方向因子、调整持有期和成交假设。它尚未经过跨月检验，也没有收益证据。

### R016：主动流与成交机会确认/冲突

修正后的目标把当前方向与未来净流对齐。确认度对同向未来流为正，但对未来活动度和波动为负，表明“方向确认”与“市场活跃”不是同一维度。四状态具有信息，但排序并非所有域都严格单调。

因此将其保留为条件状态：用于识别当前主动流是否获得成交机会支持；在跨月稳定前，不把连续交互直接作为收益因子。

### R017：盘口与成交流背离

盘口不平衡自身高度持续（对 10 分钟后盘口 IC = 0.2407），却稳定预测未来主动流反向（IC = -0.2197）。扣除盘口关系后的当前成交流残差，对未来主动净流为正（IC = 0.1445），九域和沪深均同号。

这是本轮最清楚的机制：盘口状态和主动成交方向包含两条不同、甚至相反的路径。下一步应优先做跨月复现，再检验该背离状态能否解释未来价格，而不是单独缩放盘口不平衡。

### R018：对称撤单强度

现有结果全部作废。深圳 V4 `CANCEL` 行的方向与订单 ID 正常，但 `source_price` 为 0；F013 直接用它判断是否为近端撤单，造成深圳买撤单全漏、卖撤单机械入选。详细证据见 `audits/Q005/q005_np05_sz_cancel_price_202601_v1/`。

修复必须从当日此前同侧订单状态恢复撤单原价，并覆盖集合竞价遗留订单。完成沪深事件追踪、镜像和串并行一致性测试后，使用新的 append-only F013/F014/R018 run ID 重算。

## 4. 下一步优先级

1. 优先将 R017 扩展到多个目标月，并在九分域内检查符号、衰减和收益路径。
2. 同步跨月复现 R015，把它作为活动度/波动状态和其他因子的条件变量。
3. 对 R016 冻结状态定义后做跨月排序，不提前做收益包装。
4. 停止 R014 的方向假说；如复用，只能明确标注为无方向活动状态。
5. 单独修复深圳撤单价格恢复链路并重算 R018，不重跑不受影响的 R014–R017。
