# 大价差占比因子逻辑文档

## 1. 研究目标

本文档定义基于逐笔挂单、撤单、成交事件及事件后订单簿快照构造的“大价差占比”指标，并说明其计算口径、事件处理流程、日频聚合方法、因子使用方式、质量控制和回测规范。

大价差占比刻画的是：

> 最终发生交易的被动订单，在最初进入订单簿时距离当时同侧最优报价较远的成交量，占同期总成交量的比例。

该指标不是成交时的买卖价差，也不是主动订单的成交滑点。计算的关键是把一笔成交连接到被动订单最初挂单时的订单簿状态。

主买和主卖必须分别计算、分别标准化、分别研究，不应简单视为完全对称的同一因子。

---

## 2. 数据条件

### 2.1 输入数据

每一行同时包含：

1. 事件标识：`date`、`time`、`row_id`；
2. 事件源信息：`source_kind`、`source_action`、订单 ID、成交 ID、买卖双方订单 ID、方向、价格、数量和连接状态；
3. 事件发生后的完整订单簿：`bid_px`、`bid_vol`、`bid_cnt`、`bid_ordvol`、`ask_px`、`ask_vol`、`ask_cnt`、`ask_ordvol`。

### 2.2 必要条件

准确计算原始指标需要满足：

- 数据包含真实成交事件，而不只是挂单和撤单事件；
- 成交能够通过买卖订单 ID 或对应 `recid` 连接到订单最初的新增事件；
- `date + time + row_id` 可以严格还原事件顺序；
- `source_volume` 在成交事件中代表该笔实际成交量；
- 可以可靠判断成交的主动方向；
- 事件流不存在未标识的大量缺失、重复或乱序。

若成交无法连接到被动订单的最初挂单事件，就无法严格计算其初始价差。

### 2.3 推荐样本范围

第一版研究建议：

- 只使用连续竞价；
- 排除开盘、收盘集合竞价；
- 排除大宗、协议及无法确定主动方向的特殊成交；
- 排除停牌、ST、上市时间过短及长时间涨跌停封板样本；
- 剔除订单连接率过低的股票日。

## 3. 核心定义

### 3.1 事件前盘口

每一行保存的是事件发生后的订单簿。因此，同一股票、同一交易日内严格排序后，第 i 个事件发生前的最优报价来自上一行：

```text
pre_bid1[i] = bid_px[i - 1][0]
pre_ask1[i] = ask_px[i - 1][0]
```

排序键：

```text
symbol -> date -> time -> row_id
```

同一时间戳内必须依赖 `row_id` 确定先后顺序。交易日第一条事件缺少事件前快照，原则上不用于计算新订单初始价差，除非另有开盘前订单簿状态。

### 3.2 被动买单初始价差

一张买单最初进入订单簿时：

```text
buy_initial_gap = pre_bid1 - order_price
```

含义：

- 大于 0：买单挂在当时买一之下；
- 等于 0：买单挂在当时买一；
- 小于 0：买单改善了当时最优买价。

### 3.3 被动卖单初始价差

一张卖单最初进入订单簿时：

```text
sell_initial_gap = order_price - pre_ask1
```

含义：

- 大于 0：卖单挂在当时卖一之上；
- 等于 0：卖单挂在当时卖一；
- 小于 0：卖单改善了当时最优卖价。

初始价差在订单新增时计算一次。订单后来移动到最优报价或发生部分成交时，不重新计算。

### 3.4 大价差判定

给定阈值 theta：

```text
is_large_gap = initial_gap > theta
```

原研究使用“一倍典型价差”。建议以滞后数据估计每只股票的典型价差：

```text
typical_spread[s, t] =
    median spread of stock s over trading days t-20 to t-1

normalized_gap =
    initial_gap / typical_spread[s, t]

is_large_gap =
    normalized_gap > 1
```

稳健性测试建议同时使用 0.5、1、2、3 倍典型价差。日内或日度信号都不能使用当日结束后才能获得的典型价差估计，以免产生前视。

## 4. 主买与主卖

### 4.1 主买大价差成交

主动买单与被动卖单成交。使用被动卖单最初进入订单簿时的 `sell_initial_gap` 判断：

```text
active_side = BUY
passive_order_id = source_sell_order_id
```

若被动卖单满足 `sell_initial_gap > theta`，该笔实际成交量计入主买大价差成交量。

### 4.2 主卖大价差成交

主动卖单与被动买单成交。使用被动买单最初进入订单簿时的 `buy_initial_gap` 判断：

```text
active_side = SELL
passive_order_id = source_buy_order_id
```

若被动买单满足 `buy_initial_gap > theta`，该笔实际成交量计入主卖大价差成交量。

### 4.3 主动方向识别优先级

1. 使用数据源明确提供的主动成交方向；
2. 使用 `source_order_id` 等字段识别触发当前成交的订单；
3. 比较买卖订单进入事件流的时间和 `recid`，后进入并立即成交的一方视为主动方；
4. 仍无法可靠识别的成交予以剔除。

在未验证字段语义前，不能直接假设 `source_side` 一定代表主动成交方向。

## 5. 事件流处理

### 5.1 订单状态表

按股票、交易日维护订单字典：

```text
order_state[order_key] = {
    side,
    order_price,
    entry_time,
    entry_row_id,
    entry_recid,
    initial_gap,
    normalized_gap,
    initial_volume,
    remaining_volume
}
```

推荐订单键：

```text
(date, side, order_id, order_recid)
```

若已验证订单 ID 在单个交易日内唯一，可以简化。

### 5.2 新增订单

1. 从上一行订单簿取得事件前买一、卖一；
2. 按订单方向计算初始价差；
3. 使用滞后典型价差标准化；
4. 将订单写入状态表；
5. 不得使用当前行事件后的买一、卖一计算初始价差。

### 5.3 撤单与改单

- 完全撤单：更新剩余量并关闭订单状态；
- 部分撤单：减少剩余量；
- 撤旧单后重新挂单：新订单重新计算初始价差；
- 如果订单 ID 不变但价格发生修改，价格修改应视为新订单并重新计算。

撤单不进入大价差成交分子，也不进入总成交量分母。

### 5.4 成交

1. 根据 `source_trade_id` 去重；
2. 判断主动成交方向；
3. 找到被动方订单 ID 或 `recid`；
4. 从订单状态表读取被动订单的初始价差；
5. 按 `source_volume` 累计实际成交量；
6. 更新订单剩余量；
7. 记录订单连接成功或失败。

部分成交每次按实际成交量计入，但始终使用同一个初始价差。

## 6. 日频指标

设当天全部有效连续竞价成交量为 `total_trade_volume`。

### 6.1 主买大价差占比 B

```text
B =
    sum(volume where
        active_side == BUY
        and passive_sell_initial_gap > theta)
    / total_trade_volume
```

B 描述主动买单对原本较深卖盘的实际消耗程度。

### 6.2 主卖大价差占比 S

```text
S =
    sum(volume where
        active_side == SELL
        and passive_buy_initial_gap > theta)
    / total_trade_volume
```

S 描述主动卖单对原本较深买盘的实际消耗程度。

### 6.3 合计强度 T

```text
T = B + S
```

T 主要描述深层盘口被消耗的总强度，通常与换手率、波动率和交易热度相关，但不保留方向信息。

### 6.4 方向差 D

```text
D = B - S
```

D 通常与当日收益显著正相关。原研究显示 D 与未来收益的相关性不显著，因此更适合描述当日方向或作为条件变量，不建议未经检验直接作为独立预测因子。

### 6.5 推荐输出字段

```text
symbol
date
total_trade_volume
matched_trade_volume
match_rate
large_gap_buy_volume
large_gap_sell_volume
large_gap_buy_ratio
large_gap_sell_ratio
large_gap_total_ratio
large_gap_difference
valid_trade_count
large_gap_buy_trade_count
large_gap_sell_trade_count
```

## 7. 基于研究发现的因子

### 7.1 主买、主卖独立排序

```text
factor_B = -cross_sectional_rank(B)
factor_S = -cross_sectional_rank(S)
```

原研究显示：

- 高占比组未来表现较差；
- 低占比组未来收益并不突出；
- 因子收益主要来自负向一端。

因此，B 和 S 更适合作为多头降权、尾部风险过滤或空头候选评分，而不宜直接作为对称多空因子。

### 7.2 极端收益条件反转

定义：

```text
positive_return = max(daily_return, 0)
negative_return = max(-daily_return, 0)
```

上涨方向：

```text
factor_up =
    -positive_return
    * (1 - rank(B))
    * indicator(daily_return > positive_threshold)
```

下跌方向：

```text
factor_down =
    negative_return
    * (1 - rank(S))
    * indicator(daily_return < -negative_threshold)
```

合并：

```text
large_gap_conditional_reversal =
    factor_up + factor_down
```

解释：

- 大幅上涨但 B 低：反转做空信号更强；
- 大幅上涨且 B 高：上涨得到深层卖盘消耗确认，降低做空权重；
- 大幅下跌但 S 低：反弹信号更强；
- 大幅下跌且 S 高：深层买盘被持续消耗，降低抄底权重。

正负阈值可以先取 2%，也可以使用波动率标准化收益或每日截面分位数。上涨和下跌不应强制使用完全相同的系数。

该公式是对研究结论的可交易化表达，原研究没有直接展示该公式的回测结果，必须进行样本外验证。

### 7.3 低波动区间条件动量

原研究显示，当日收益位于约 -2% 至 2% 时，缺乏明确的短期反转；主卖指标低占比组的未来收益高于主买指标低占比组。

可定义：

```text
quiet_momentum =
      positive_return
      * (1 - rank(S))
      * indicator(0 < daily_return <= threshold)

    - negative_return
      * (1 - rank(B))
      * indicator(-threshold <= daily_return < 0)
```

其中 `threshold` 可先取 2%。

含义：

- 小幅上涨且 S 低：偏多；
- 小幅下跌且 B 低：偏空。

### 7.4 不推荐的直接用法

- 直接把 B + S 当作方向性收益因子；
- 直接把 B - S 当作未经控制的未来收益预测因子；
- 强制主买、主卖使用完全对称的系数；
- 假设占比越低未来收益一定越高；
- 只使用线性 IC 概括明显非线性的分组关系。

## 8. 标准化和中性化

主买与主卖的无条件水平不同，必须分别标准化。

### 8.1 时间序列标准化

```text
z_B[s, t] =
    (B[s, t] - rolling_mean(B[s], 20 or 60 days))
    / rolling_std(B[s], 20 or 60 days)

z_S[s, t] =
    (S[s, t] - rolling_mean(S[s], 20 or 60 days))
    / rolling_std(S[s], 20 or 60 days)
```

滚动统计量必须严格滞后。

### 8.2 截面中性化

如有外部基础数据，建议分别对 B、S 控制：

- 当日正收益、负收益；
- 日内振幅；
- 实现波动率；
- 成交额、换手率；
- 普通买卖价差；
- 股价；
- 市值；
- 行业；
- 上市板块。

示意：

```text
B = f(
    positive_return,
    absolute_return,
    intraday_range,
    realized_volatility,
    turnover,
    quoted_spread,
    price,
    market_cap,
    industry,
    board
) + residual_B

S = f(
    negative_return,
    absolute_return,
    intraday_range,
    realized_volatility,
    turnover,
    quoted_spread,
    price,
    market_cap,
    industry,
    board
) + residual_S
```

若研究目标是检验大价差指标的增量信息，应重点检验 `residual_B`、`residual_S`。

## 9. 数据质量控制

### 9.1 订单连接率

```text
match_rate =
    successfully_matched_passive_trade_volume
    / valid_total_trade_volume
```

建议：

- 输出每日、每只股票的连接率；
- 第一版剔除连接率低于 95% 的股票日；
- 检查连接失败是否集中在开盘、尾盘和极端行情。

### 9.2 成交去重

以 `source_trade_id` 为主要去重键，并结合 `recid` 验证一笔成交是否产生多条订单更新记录。总成交量和大价差成交量必须采用相同去重口径。

### 9.3 最低样本要求

低成交量股票日的比例容易被单笔交易支配。建议设置：

- 最低有效成交笔数；
- 最低有效成交额或成交量；
- 最低连接成功成交量；
- 单笔成交对分子的最大贡献比例标记。

### 9.4 盘口有效性

下列情形不计算订单初始价差：

- 事件前同侧最优报价为空；
- 事件前盘口异常；
- 事件顺序无法确定；
- 订单价格缺失或非法；
- 事件不属于纳入研究的交易阶段。

## 10. 潜在偏差

### 10.1 机械内生性

大价差订单之所以成交，通常是因为价格已经向某一方向移动。大价差占比可能是当日收益、振幅和价格路径的结果，而不是价格变化的原因。

### 10.2 成交样本选择偏差

指标只观察最终成交的深层订单，不包含未成交或被撤销的深层订单。因此，它刻画的是“初始深度与后续价格路径的联合结果”，不是全部深层流动性供给。

### 10.3 订单年龄混淆

深层订单通常更早进入订单簿。建议同步记录：

```text
order_age = trade_time - entry_time
```

并检验控制订单年龄后指标是否仍有增量信息。

### 10.4 日内路径依赖

相同开收盘收益可能对应不同的日内路径。往返波动可能同时提高 B 和 S，因此需控制日内振幅、实现波动率和路径曲折程度。

### 10.5 非线性及单边贡献

原研究显示，预测力可能主要来自高占比差股票，低占比多头组并不强。应分别评估多头端、空头端和极端分组，不能只看整体 IC。

## 11. 回测规范

### 11.1 可交易时点

完整日频因子只能在当日收盘后获得。最早可交易时点应为下一交易日开盘或下一交易日 VWAP。不得使用当日收盘价模拟已经使用当日全部事件计算出的信号。

### 11.2 收益区间

建议分别评估：

- 当日收盘至下一日开盘；
- 下一日开盘至下一日收盘；
- 下一日开盘至未来第 5 日收盘；
- 下一日 VWAP 至未来第 5 日 VWAP。

### 11.3 分组检验

主买、主卖分别进行：

- 单变量十组；
- 当日收益 × 大价差占比二维分组；
- 市值或流动性分层；
- 正收益与负收益样本分开；
- 极端涨跌与低波动样本分开。

### 11.4 统计要求

- 五日收益存在重叠，应使用 Newey-West、日期聚类或非重叠样本；
- 报告 IC 均值、ICIR、胜率和分年度结果；
- 报告多头端、空头端各自贡献；
- 检验不同阈值、窗口和过滤条件；
- 使用样本外时期验证；
- 纳入换手、冲击成本和融券可行性。

## 12. 推荐实施顺序

### 阶段一：指标复现

1. 验证事件类型和主动方向字段语义；
2. 建立订单生命周期状态表；
3. 计算每张订单的初始价差；
4. 将成交连接到被动订单；
5. 分别生成日频 B、S、T、D；
6. 完成连接率、成交量和分布质检。

### 阶段二：复现研究事实

1. 检验 B 与当日收益的正相关；
2. 检验 S 与当日收益的负相关；
3. 检验 B、S 与交易热度的关系；
4. 分别完成未来五日收益十组检验；
5. 复现低波动与极端涨跌状态下的未来收益差异；
6. 检验 B - S 与当日、未来收益的关系。

### 阶段三：因子研究

优先测试：

1. 主买、主卖高占比的风险过滤效果；
2. 极端收益条件反转因子；
3. 低波动区间条件动量因子；
4. 控制收益、换手、波动、振幅和订单年龄后的增量信息；
5. 不同阈值及不同市场状态下的稳定性。

---

## 13. 最终解释

大价差占比不应被解释为纯粹的订单深度变量。更准确地说，它衡量的是：

> 原本位于订单簿较深位置的被动流动性，在当日价格演化过程中被主动交易实际消耗的程度。

因此，该指标同时包含订单初始深度、订单年龄、价格方向、日内路径、交易热度和信息冲击。其最有价值的用途可能不是作为独立单调因子，而是作为短期反转因子的条件变量，用于区分暂时性价格压力和相对持久的价格变化。
