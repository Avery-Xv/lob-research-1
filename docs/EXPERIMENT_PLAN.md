# 日内与 Event LOB 实验总计划

更新日期：2026-08-06

## 1. 文档定位与状态

本文是当前日内和事件级 LOB 研究的统一总账，用于记录已完成基线、代码就绪待运行、待实现实验、依赖关系和停止项。后续执行前先查看本表，实验完成后补充产物路径与结论，避免重复扫描和重复分类。

- DONE：已有正式产物和可引用结论。
- READY：实现与小样本测试已完成，正式计算或回测尚未运行。
- TODO：尚未实现。
- GATED：依赖前序实验通过后才做。
- STOP：已有否证或与其他系列重复，不再单独立项。

## 2. 当前统一口径

1. 默认先报告 raw、不做评估中性化的结果。
2. 风格、行业和 LOB 中性化仅在明确要求时运行，或作为 raw 之后单独标注的稳健性检查，不能替代 raw 基准。
3. 因子定义所需的残差化仍保留，例如 D04 的控制变量残差、NP01 对 M1 的条件增量；回测阶段不再自动追加中性化。
4. 使用点时点 A 股股票池，因子计算前排除 ETF，并在正式产物中记录 ETF=0。
5. 先确定信号时点股票池，再按各预测期独立过滤缺失标签。
6. 日内主窗口为 10:00–10:30。收益从信号完成后开始，默认检查 5、10、15、30 分钟，具体入场和退出价写入 metadata。
7. 中间价用于机制研究，bid/ask 和交易约束用于可执行性解释。

## 4. M00：已完成的 M 系列基线

### 4.1 样本

- 2026 年 1 月，20 个交易日；
- 300 只点时点 A 股，ETF 为 0；
- 每日 21 个固定信号时点；
- 过去特征窗口为 (t-60s,t)，直接目标为 [t,t+10m)；
- 当前结论是订单流、盘口、活动度和波动机制，不是未来收益 alpha。

### 4.2 已确认结论

| 机制 | 已有结果 | 后续处理 |
|---|---|---|
| M1 普通主动流 | 后10分钟主动流 IC 约0.1412，跨九域和21时点同向 | 保留为基准和控制 |
| M2 买侧相对刺激 | 原预设方向未复现 | STOP |
| M3 上涨刺激集中度 | 未复现；事件时钟仅缩小反向结果 | STOP |
| M4 高强度薄簿 | 总体与预设相反，低价非 STAR 是例外 | 转入吸收和冲击效率 |
| M5 高热度厚簿 | 总体约 +0.048 log depth，明显域依赖 | 只作为条件状态 |
| M6 成交机会差 | 控制三次 M1 后直接目标 IC 约0.0093、t=2.40 | 进入 NP01 和收益闸门 |
| 当前盘口不平衡 | 预测未来盘口为正，预测未来主动流为负 | 进入 NP04 |
| 带方向撤单差 | 对未来实现波动 IC 约0.2820 | 先做镜像和对称强度 |

M 系列是 NP 和 MSI 的共同主干，不再作为待做实验重复计算。

## 5. AG01：active_gap 扩样

### 5.1 已有结果

2026 年 1 月约20个交易日的 10:00–10:30 信号中：

- old_active_abs raw D10-D1：10分钟约15.16 bp，t=3.99；15分钟约21.19 bp，t=3.69；
- old_active_ratio 较弱，但仍有尾部候选价值；
- signed 版本弱，仅保留诊断；
- 信号更像极端组效应，而不是稳定线性排序。

### 5.2 待做

1. 使用点时点 A 股 manifest 扩到 2026-02～04，与 joint large_gap/order behavior 的57日样本对齐。
2. 一次读取同时输出 absolute、ratio、signed、事件数和共享 primitive。
3. raw 主结果检查 5、10、15、30 分钟 Rank IC、D10-D1、顶部和底部独立收益。
4. 固定 10%、20%、30% 宽尾部分组，不按结果选择截断宽度。
5. 分月报告方向、t 值、有效股票数和极端组样本数。
6. raw 稳定后再检查 bid/ask 可执行收益、涨跌停和成本。

通过条件：多数月份同方向；至少一个预注册期限的 raw 尾部价差稳定；效果不由单日、单域或极少数股票驱动；可执行口径不反向。

## 7. ELOB01–ELOB04：Event-LOB 最小实证

四项均来自 docs/Event_LOB最小实证实验方案.md，当前为 TODO。

### ELOB01：Imbalance × spread 与下一次中价变化

- Top1 imbalance z-score 与 1、2、3、4、5+ tick spread；
- 标签为下一次有效中价变化方向；
- 输出10分位主曲线、20分位稳健性、logit 交互、样本数和按交易日 block bootstrap 置信区间。

### ELOB02：多跳价格响应

- 记录第1、2、3、5、10次未来中价跳动后的累计响应；
- 按 imbalance 和 spread 分层；
- 将形状分类为持续、一次性或反转。

### ELOB03：信号兑现时间

- 计算1、5、10、30、60秒内首次中价变化；
- 输出中位等待时间、兑现概率和 Kaplan–Meier 曲线；
- 分开处理首次上涨和首次下跌的竞争方向。

### ELOB04：Add/Cancel/Trade 事件价格 IRF

- 事件规模除以事件前同侧队列；
- 事件时间检查1、2、5、10、20、50、100个事件；
- 自然时间检查1、5、10、30、60秒；
- 做买卖镜像、imbalance/spread 条件化和事件类型交互。

公共实施：先用12只股票、3日验证事件顺序；正式第一阶段使用 M 系列同口径的 2026-01 medium300；四项实验和 NPE 公共 primitive 在每个 stock-month 的一次扫描中生成。主统计为 stock-day 等权，pooled event 只作对照，显著性按交易日 block bootstrap。

## 9. NPE 与 DR：非母单事件深化

| ID | 方向 | ELOB 可复用部分 | 独有新增量 |
|---|---|---|---|
| NPE01 | 流动性吸收 | 多跳路径、Event IRF | 主动量与深度损失联合状态 |
| NPE02 | 冲击效率 | Event IRF、相对队列规模 | 穿透档位与单位主动量冲击 |
| NPE03 | 历史恢复能力 | 事件后价格路径 | 补单、点差和深度恢复轨迹 |
| NPE04 | 日内热度惊奇 | 事件到达数 | 严格滞后的历史同时段基线 |
| NPE05 | 秒时钟与事件时钟 | 两套时间轴 | 同一状态量的时钟差异 |

DR01–DR05 的近端大单遮挡、显露、深层撤单响应和订单生命周期属于 NPE 的嵌套方向。它们复用 ELOB 的事件顺序和价格路径，但需要独有的订单级深档生命周期。DR 不与 NP、MSI 并列为第三条结构主线。

## 10. MSI01–MSI10：母单结构系列

| 阶段 | 实验 | 进入下一阶段的条件 |
|---|---|---|
| MSI-A | MSI01 链集中度、MSI02 碎片化与熵 | 相对普通 M1 有结构增量 |
| MSI-B | MSI03 节奏加速、MSI04 continuation/termination | 在线状态不使用未来链信息 |

| MSI-D | MSI08 episode 置信度、MSI09 频率结构 | 规则型基线优于简单活动度 |

第一版使用 medium300 和与 M 系列一致的历史预热。现有母单链流约98.5%的域内截面方差可被 M1 和既有控制解释，因此 MSI 必须证明结构变量相对 M1 的增量，不能以单变量高 IC 作为成功标准。
